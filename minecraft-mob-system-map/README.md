# Minecraft 1.12.2 Mob-System Map

This folder contains a Graphify knowledge map of Minecraft 1.12.2's vanilla
mob system. The existing Zomboid Zombies mod workspace remains untouched and
available for later implementation work.

## Open the map

Open `graphify-out/graph.html` in a browser. Because the complete graph has
9,214 nodes, the HTML view is intentionally aggregated into 325 communities.
Use `graphify-out/graph.json` or Graphify queries for full class/method-level
detail.

The JSON graph, HTML visualization, manifests, labels, caches, and decompiled
source corpus are intentionally ignored by Git. They remain available locally,
while only `GRAPH_REPORT.md` and `GRAPH_HEALTH.txt` are kept in project review.
This avoids sending hundreds of thousands of generated lines through Codex
task synchronization.

From this directory:

```powershell
graphify query "How does a zombie select a target and request a path?"
graphify path "EntityZombie" "PathNavigateGround"
graphify explain "EntityAITasks"
```

## Corpus scope

The local `corpus/` directory was extracted from the MCP 1.12.2 joined,
decompiled source archive generated by ForgeGradle. It contains 478 Java files
and is ignored by Git so decompiled Minecraft sources are not accidentally
committed.

Included in full:

- `net.minecraft.entity` — base entities, living entities, mobs, players,
  bosses, projectiles, AI tasks, senses, helpers, and attributes
- `net.minecraft.pathfinding` — navigators, node processors, paths, heaps,
  points, and world listeners
- `net.minecraft.world.biome` — biome spawn lists and creature categories
- Entity data synchronization, NBT persistence, potion effects, equipment
  inventory, registries, math primitives, and loot support

Included selectively:

- World spawning and difficulty classes
- Mob spawner tile entities and dungeon generation
- Blocks and block-state/material classes used by navigation
- Entity spawn/state network packets
- Core items and combat utilities used by mobs

Rendering, GUI, recipes, unrelated world generation, and other systems were
excluded so the graph remains focused on mob behavior.

## Graph health

The integrity diagnostic is saved in `graphify-out/GRAPH_HEALTH.txt`. Dangling
endpoints are expected where included mob classes reference Minecraft systems
outside this focused corpus. Duplicate and collapsed edges primarily represent
repeated field/type references in registry classes. The full raw extraction
contained 9,254 nodes and 36,078 relationships; the built undirected graph
contains 9,214 nodes and 27,780 unique edges.
